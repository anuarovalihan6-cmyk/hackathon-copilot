# Hackathon Copilot

[English instructions](README.md).

Небольшой помощник для подготовки к хакатону, создаваемый по официальному Devpost Learn Skill Pack.

Публичный репозиторий: [anuarovalihan6-cmyk/hackathon-copilot](https://github.com/anuarovalihan6-cmyk/hackathon-copilot). Основная ветка — `main`.

Демонстрация (2 минуты): [YouTube](https://youtu.be/GnGB1JhI_1g).

Лицензия: [MIT](LICENSE), Copyright (c) 2026 alikhan.

## Текущее состояние

Работают создание и исправление хакатона с названием и дедлайном, задачи с необязательным ответственным и отметкой выполнения, прогресс, новости со ссылками, редактирование/удаление записей, сохранение/отмена исправлений, EN / RU и сохранение в браузере. Первая версия проверена, финальный просмотр завершён; подготовка публикации отмечена в [журнале разработки](devpost/checklist.md).

Кнопка **Добавить стартовый план** добавляет шесть задач от идеи до заявки, сохраняя прежние записи. Повторных копий не создаёт; удалённые шаги можно явно восстановить. Исходные названия готовых шагов показываются на выбранном EN/RU, в том числе у ранее добавленных задач. Ручные и переименованные задачи сохраняют свой текст. Карточка **Следующий шаг** показывает первую невыполненную задачу и переводит к ней. Дни рядом с дедлайном считаются по местной календарной дате, без точного времени подачи.

## Запуск

Нужен Node.js 24.x (в текущем окружении установлен 24.17.0). Сторонних npm-зависимостей нет, `npm install` не требуется.

В папке проекта:

```sh
npm start
```

Открыть **http://127.0.0.1:4173/** в обычном окне браузера. Сервер слушает только этот компьютер. Остановить: Ctrl+C в терминале запуска.

Используйте один и тот же адрес и профиль браузера: сохранённое относится к сочетанию адреса, протокола и порта. После остановки сервера данные остаются в браузере; для нового открытия страницы запустите сервер снова. Прямое открытие `index.html` не является поддерживаемым способом запуска.

## Сохранение

Данные лежат в `localStorage` под ключом `hackathon-copilot:v1`. Очистка данных сайта удалит записи. Между устройствами они не синхронизируются; в приватном окне сохранение после закрытия не гарантируется. При ошибке записи приложение сообщает об этом и оставляет данные видимыми в текущем открытии. Повреждённое сохранённое не перезаписывается автоматически.

## Проверки

```sh
npm test
```

Встроенный test runner Node.js проверяет даты, сохранённую схему, задачи и новости, исправления и удаление, прогресс, восстановление данных и языка, ошибки хранения и ограничение выдачи файлов локальным сервером. Проверки в браузере и их границы фиксируются в `devpost/checklist.md`.
