Справочный маршрут: три остановки

Можно открыть эти файлы и найти указанные имена. Это маршрут для возвращения к проекту; отдельное упражнение проходить не требуется.

  1. src/main.js — обработчик [data-language]

    Кнопка меняет data.language, затем вызывает saveAndRender. Там сохранение и отображение соединяются.

  2. src/model.js — starterStepForTask и taskDisplayTitle

    Стабильный id и исходное название определяют готовый шаг. Совпадения одного текста недостаточно: обычная ручная задача сохраняется дословно.

  3. src/ui.js — renderTasks, renderGuide и beginEdit

    Одна функция выбора названия применяется в списке, карточке и при открытии редактора. Уже открытый черновик при смене языка остаётся прежним.

Приём для следующего проекта

При проверке обнаружилось расхождение: EN переводил кнопки, а готовые задачи оставались на русском. Требование уточнили в devpost/prd.md → Interface Language, правило вынесли в одну функцию и добавили примеры в tests/plan.test.js.

Полезная привычка: описать видимый пример ошибки, записать ожидаемый результат и проверить его после исправления. В другом проекте такой пример помогает отличить настоящий результат от предположения «должно работать».

Как снова открыть приложение

В папке проекта выполни:

npm start

Открой http://127.0.0.1:4173/. Используй прежний браузер и адрес, чтобы вернуться к сохранённым данным. Если сервер уже работает, запускай только страницу.

Проверки: npm test. Нужен Node.js 24.x; npm install не требуется. Подробности — в README.md.
