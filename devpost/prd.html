Поведение первой версии

Теперь у идеи есть конкретный путь: создать хакатон, организовать работу команды и вернуться к сохранённой подготовке.

Одна страница, два языкаEN / RU доступны при первом запуске и во время работы. Данные и выбранный язык сохраняются.

  5. ВозвращениеВ том же браузере доступны сохранённые данные и выбранный язык.

03

Действия и проверка результата

Раскрой нужный раздел: внутри видно, что делает пользователь и как проверить поведение.

Первый запуск и хакатон
Что происходит

Под Build your MVP сразу есть поля названия и дедлайна, кнопка Start preparing. После добавления хакатона появляется рабочая часть той же страницы.

Проверка: введённые название и дедлайн видны над задачами. Переключатель EN / RU доступен до заполнения формы.

Задачи и ответственные

Task name + необязательный Assignee → Add task. Ответственного вписываешь вручную, в том числе после добавления задачи.

Edit меняет название и ответственного. Delete удаляет задачу. Отметка выполнения влияет на прогресс.

Проверка: задача без ответственного показывает Unassigned / Не назначен. После назначения видимо введённое имя.

Новости и источники

News title + Link → Add news. Новость добавляешь вручную. Сохранённая запись позволяет открыть источник.

Edit исправляет заголовок и ссылку. Delete удаляет запись. По новости ты сам решаешь, какую задачу добавить команде.

Проверка: новость видна в списке под задачами; её ссылка открывает источник. Автоматические новости оставлены на будущее.

Переключение EN / RU

Меняются все заголовки, подписи полей, кнопки, подсказки, пустые состояния и ошибки. Например: Build your MVP → Создай свой MVP.

Введённые названия, имена и тексты сохраняются в исходном виде. Ручной выбор языка запоминается даже до создания хакатона.

Проверка: при смене языка сохраняются записи и текст в открытых полях. После повторного открытия используется выбранный язык.

Прогресс подготовки

Полоса прогресса расположена сверху. Расчёт — доля выполненных задач с процентом и счётчиком выполнено / всего.

Отметку можно поставить и снять. После добавления или удаления задачи показатель пересчитывается.

Проверка: нет задач → 0%; все существующие задачи выполнены → 100%. Обратная отметка меняет прогресс снова.

Сохранение и возвращение

Сохраняются хакатон, дедлайн, новости, задачи, ответственные, отметки и выбранный язык. Подготовкой управляет один человек на своём компьютере.

Проверка: закрыть и снова открыть приложение в том же браузере — данные и выбор EN / RU доступны для продолжения работы.

04

Правила первой версии

Эти простые правила согласованы вместе с PRD: дедлайн задаётся датой без времени, начальный язык выбирается по браузеру, ручной выбор EN / RU сохраняется.

Формы и исправления

  • Дедлайн — календарная дата без отдельного времени.
  • Название хакатона и дедлайн обязательны. Их можно исправить через Edit hackathon.
  • Название задачи обязательно, ответственный необязателен.
  • Заголовок новости и ссылка на веб-страницу обязательны.
  • Save changes применяет исправления; Cancel оставляет прежнюю запись.

Пустые списки и язык

  • Нет задач: No tasks yet, приглашение добавить задачу и прогресс 0%.
  • Нет новостей: No updates yet и приглашение добавить новость вручную.
  • При первом открытии русский выбирается для браузера с русским языком, иначе — английский.
  • После ручного выбора EN / RU используется сохранённый язык.
  • Все эти сообщения переводятся вместе с интерфейсом.
Что происходит при ошибке

Пустое обязательное поле или непригодная ссылка: рядом с полем появляется понятная подсказка. Запись не добавляется; введённый текст остаётся для исправления.

Ошибка сохранения в браузере: появляется понятное сообщение об ошибке. Уже введённые данные остаются видны в текущем открытии.

Выбранное направление

Тёмный фон, светлый текст, яркие акценты на кнопках и прогрессе, плавные анимации. Точные оттенки и приёмы определим в техническом плане. Изучены примеры из твоих референсов, открытые главы Refactoring UI и рекомендации по читаемости и движению; выводы сохранены для будущего дизайна.

План подготовки — от идеи к заявке

Кнопка добавляет шесть обычных задач на выбранном языке, сохраняя прежние записи. Повторных копий нет; удалённые шаги можно явно восстановить. Названия затем остаются редактируемым текстом.

Карточка «Следующий шаг» показывает первую невыполненную задачу с подсказкой. «К задаче» переводит к её отметке. Без задач и после выполнения всех показываются отдельные состояния. У даты видны календарные дни; точное время подачи не задаётся.
